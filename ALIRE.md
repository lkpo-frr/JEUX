## Important : a faire pour que le site marche

* Executer le script sql scriptcomplet.sql dans phpmyadmin pour mettre à jour les bases de données

* Changer l'utilisateur, le mot de passe et le nom de la base de données si besoin dans connexion.php

* Ouvrir scriptInsertionImages.php et appuyer sur le bouton qui s'affiche pour insérer les images dans la base de données
